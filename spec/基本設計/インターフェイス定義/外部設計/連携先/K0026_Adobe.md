| :------------- | :--------------------------------------------------------------------------------------------------------------- |

| 改行コード     | CRLF                                                                                                             |

|                | ①就業者情報.AcrobatDC利用がtrueに設定された （⑲ソフトウェア購入に関する申請_v2（Acrobat DC用）で承認されたもの） |
