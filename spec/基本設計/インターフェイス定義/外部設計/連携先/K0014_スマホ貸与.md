## ユーザーデータファイル
社給のスマートフォンを貸与する就業者のリストを連携するファイル。

### ファイルフォーマット
| 項目           | 内容                                                                                                                                                                                                              |
| :------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 種類           | csv                                                                                                                                                                                                               |
| ファイル名     | ユーザーデータ.csv                                                                                                                                                                                                |
| 文字コード     | UTF-8                                                                                                                                                                                                             |
| 改行コード     | CRLF                                                                                                                                                                                                              |
| タイトル行     | あり                                                                                                                                                                                                              |
| エスケープ     | なし                                                                                                                                                                                                              |
| 全量／差分     | 差分                                                                                                                                                                                                              |
| 連携タイミング | 就業者情報.基準日（内示日 or 電子承認の貸与希望日）の5営業日前                                                                                                                                                    |
| 抽出条件       | 次の①②のどちらかに該当する就業者                                                                                                                                                                                  |
|                | ①就業者情報.就業者区分が(役員、社員)のいずれか　かつ　新規登録（就業者情報.基準日＝就業者情報.入社日／契約開始日）                                                                                                |
|                | ②就業者情報.就業者区分が(直接雇用スタッフ、直接雇用シニアスタッフ、派遣社員)のいずれか　かつ　就業者情報.携帯電話貸与日が未設定から設定されたもの(電子承認「役員・社員以外の者への会社携帯電話貸与申請書」承認時) |
