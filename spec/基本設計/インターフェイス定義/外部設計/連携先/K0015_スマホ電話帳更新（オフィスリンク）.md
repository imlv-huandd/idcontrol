## ユーザーデータファイル
所属部署が異動となり社給のスマートフォンの電話帳を更新する必要のある就業者のリストを連携するファイル。

### ファイルフォーマット
| 項目           | 内容                                                                                                                                |
| :------------- | :---------------------------------------------------------------------------------------------------------------------------------- |
| 種類           | csv                                                                                                                                 |
| ファイル名     | ユーザーデータ.csv                                                                                                                  |
| 文字コード     | UTF-8                                                                                                                               |
| 改行コード     | CRLF                                                                                                                                |
| タイトル行     | あり                                                                                                                                |
| エスケープ     | なし                                                                                                                                |
| 全量／差分     | 差分                                                                                                                                |
| 連携タイミング | 就業者所属情報.基準日の5営業日前（内示日）                                                                                          |
| 抽出条件       | 次の①②のどちらかに該当し、③④のどちらかに該当する就業者                                                                              |
|                | ①就業者情報.就業者区分が(役員、社員)のいずれか                                                                                      |
|                | ②就業者情報.就業者区分が(直接雇用スタッフ、直接雇用シニアスタッフ、派遣社員)のいずれかで、就業者情報.携帯電話貸与日が設定されている |
|                | ③就業者情報.姓、名、メールアドレスのいずれかが変更となったもの(新規登録、退職は除く)                                                |
|                | ④就業者所属情報(主務).組織コードまたは役職コードが変更となったもの(新規登録、退職は除く)                                            |
| その他         | 値を出力する項目（必須が○のもの）は**差分がある項目のみ出力**する                                                                   |
