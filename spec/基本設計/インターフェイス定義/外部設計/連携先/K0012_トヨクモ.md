## トヨクモユーザ部署情報ファイル
### ファイルフォーマット
| 項目           | 内容               |
| -------------- | ------------------ |
| 種類           | CSV                |
| ファイル名     | ユーザ所属地域.csv |
| 文字コード     | Shift_Jis          |
| 改行コード     | CRLF               |
| タイトル行     | あり               |
| エスケープ     | なし               |
| 全量／差分     | 全量               |
| 抽出条件       | なし               |
| 連携タイミング | 発令日             |

### 出力項目
| No  | 項目名       | 種別 | 桁数 | 必須 | 項目説明                           | 設定先マスターデータ                              |
| --- | ------------ | ---- | ---- | ---- | ---------------------------------- | ------------------------------------------------- |
| 1   | 現部署コード | 文字 | 256  | 〇   | 変更前の部署コード                 | 組織情報.グループコードをコード変換マスターで変換 |
| 2   | 部署名       | 文字 | 256  | 〇   | 部署の名称                         | 組織情報.組織名称                                 |
| 3   | 新部署コード | 文字 | 256  | 〇   | 変更後の部署コード                 | 組織情報.グループコードをコード変換マスターで変換 |
| 4   | 親部署コード | 文字 | 256  | 〇   | この部署の親となる部署の部署コード | 組織情報.グループコードをコード変換マスターで変換 |

更新の必要のない項目には"*"を設定する。

### 確認事項
* 常に全量投入することを想定しているため、過去データの情報は使用しない（＝現部署コードは常に新部署コードと同じ。変わっていた場合、過去の部署は削除される。）で問題ないか。

| No  | 項目名         | 種別 | 桁数 | 必須 | 項目説明                                                                         | 設定先マスターデータ                        |

### 確認事項
* 常に全量投入することを想定しているため、過去データの情報は使用しない（＝現ログイン名は常に新ログイン名と同じ。）で問題ないか。
