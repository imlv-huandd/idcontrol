# マスターデータ定義

当システムにおいて、就業者等の情報として管理するデータは下記の通り。

## 就業者情報

就業者の、個々人に紐づく情報を管理するマスター。
初期登録時から、紐づく情報が変更されたタイミング(基準日)ごとの履歴を持つ。

## 組織情報
組織の情報を管理するマスター。各組織は親となる組織（グループ／役職）の情報を持ち、ツリー構造を持つ。
ある基準日で1件以上組織が変更された場合、全ての組織情報がその日基準のデータを持つ。

## 役職情報
役職の情報を管理するマスター。各組織は親となる組織（グループ／役職）の情報を持ち、ツリー構造を持つ。
ある基準日で1件以上役職が変更された場合、全ての役職情報がその日基準のデータを持つ。

### 保持項目

| No. | 項目名     | データ種別 | 項目説明                                           | 設定元(OBIC) | 設定元(電子承認) |
| --: | :--------- | :--------: | :------------------------------------------------- | :----------- | :--------------- |
|   1 | 役職コード |            | 役職を特定するコード                               |              |                  |
|   2 | 役職名称   |            | 役職の名称                                         |              |                  |
|   3 | 基準日     |            | この情報が有効となる日付                           |              |                  |
|   4 | 廃止日     |            | 組織が廃止となった日付                             |              |                  |
|   5 | 序列       |            | 役職の序列。数値が小さいほど上位であることを表す。 |              |                  |
|   6 | ポスト長   |            | この役職がポスト長であることを表すフラグ           |              |                  |
|   7 | 経営管理職 |            | この役職が経営管理職であることを表すフラグ         |              |                  |
|   8 | 専門職     |            | この役職が専門職であることを表すフラグ             |              |                  |
|   9 | OBIC役職   |            | OBIC上の役職名                                     |              |                  |


## 就業者所属情報
就業者と組織、役職の所属関係を管理するマスター。
就業者情報、組織情報、役職情報とは別に所属情報の有効期間を持つ。


### 保持項目

| No. | 項目名                 | データ種別 | 項目説明                                                           | 設定元(OBIC)                              | 設定元(電子承認) |
| --: | :--------------------- | :--------: | :----------------------------------------------------------------- | :---------------------------------------- | :--------------- |
|   1 | マンナンバー           |            |                                                                    |                                           |                  |
|   2 | 基準日                 |            | この情報が有効となる日付                                           |                                           |                  |
|   3 | 廃止日                 |            | この情報が無効となった日付                                         |                                           |                  |
|   4 | 部門コード(基軸コード) |            |                                                                    |                                           |                  |
|   5 | 役職コード             |            |                                                                    |                                           |                  |
|   6 | 主務部署               |            | この情報が就業者のメインの所属の情報かを表すフラグ。               |                                           |                  |
|   7 | OBIC兼務発令コード     |    文字    | 兼務情報の場合に設定。OBICで設定された事務取扱／兼務時の発令コード | 社員情報（事務取扱・兼務）.兼務発令コード | 設定しない       |



参照する際は就業者情報と組織情報、役職情報を連結したデータを提供する。
イメージは下記の通り。（複数部署に所属がある場合はその分だけ就業者情報が出力される。就業者情報はどのデータも同じものとなる）
**| ---就業者情報--- | ---就業者所属情報--- | ---組織情報--- | ---役職情報--- |**

## 連携先システム情報
就業者に紐づく、連携先システムに連携するデータ(※)の情報を管理するマスター。
各就業者ごとに、システムとその連携先ごとの出力内容を持つ。
※インターフェイスを出力無しとすることで実質的に連携しないデータも含める。
