# マスターデータ定義

当システムにおいて、就業者等の情報として管理するデータは下記の通り。

## 就業者情報

役員／社員／契約社員／スタッフなどの個々人に紐づく情報を管理するマスター。
初期登録時から、紐づく情報が変更されたタイミングごとの履歴を持つ。

## 組織情報
グループ及び役職の情報を管理するマスター。各組織は親となる組織（グループ／役職）の情報を持ち、ツリー構造を持つ。
どこかのツリー構造が変更されるタイミングごとの履歴を持つ。

### 保持項目
| No. | 項目名     | 項目説明                                   |
| --: | :--------- | :----------------------------------------- |
|   1 | 所属コード |                                            |
|   2 | 所属名称   |                                            |
|   3 | 基準日     | この情報が有効となる日付                   |
|   4 | 廃止日     | この組織は廃止となった日付                 |
|   5 | 表示順     | 共通の親を持つ組織の中で何番目に表示するか |


## 就業者所属情報
就業者と組織の所属関係を管理するマスター。
就業者情報、組織情報とは別に所属情報の有効期間を持つ。


### 保持項目

| No  | 項目名       | 項目説明                           |
| --- | ------------ | ---------------------------------- |
| 1   | マンナンバー |                                    |
| 2   | 所属コード   |                                    |
| 3   | 所属名称     |                                    |
| 4   | 役職コード   |                                    |
| 5   | 役職名称     |                                    |
| 6   | 主務部署     | 就業者の主たる所属かを表すフラグ。 |


管理項目としては上記の通りだが、参照する際は就業者情報と組織情報を連結したデータを提供する。
イメージは下記の通り。（複数部署に所属がある場合はその分だけ就業者情報が出力される。就業者情報はどのデータも同じものとなる）


| ---就業者情報--- | ---就業者所属情報--- | ---組織情報--- |
| 社--------------. | 主------------------日 | グ------------. |

例：
012345,N田,T郎,....主務, 2025/12/01,1210123456,0092,...
012345,N田,T郎,....兼務, 2026/01/01,1210123457,0094,...
012346,T山,G郎,....主務, 2020/08/01,1210223344,0094,...
