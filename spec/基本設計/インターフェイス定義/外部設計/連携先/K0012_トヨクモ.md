## トヨクモ部署情報ファイル
存在する部署と部署の親を連携するファイル。

### ファイルフォーマット
| 項目           | 内容                                                                                                                    |
| :------------- | :---------------------------------------------------------------------------------------------------------------------- |
| 種類           | csv                                                                                                                     |
| ファイル名     | トヨクモ部署情報.csv                                                                                                    |
| 文字コード     | UTF-8                                                                                                                   |
| 改行コード     | CRLF                                                                                                                    |
| タイトル行     | あり                                                                                                                    |
| エスケープ     | なし                                                                                                                    |
| 全量／差分     | 全量                                                                                                                    |
| 連携タイミング | 組織情報.基準日（発令日）の一週間前（5営業日前）                                                                        |
| 抽出条件       | 廃止でないもの（基準日≧廃止日でないもの）                                                                               |
| その他         | 登録済でファイルにないデータは削除される為、変更前の組織情報参照はしない。<br>部署コードにはEMILY所属コードを使用する。 |

### 出力項目
|  No | 項目名       | 種別 | 桁数 | 必須 | 項目説明                           | 設定先マスターデータ                            |
| --: | :----------- | :--: | :--: | :--: | :--------------------------------- | :---------------------------------------------- |
|   1 | 現部署コード | 文字 | 256  |  ○   | 変更前の部署コード                 | 組織情報.EMILY所属コード                        |
|   2 | 部署名       | 文字 | 256  |  ○   | 部署の名称                         | 組織情報.所属名称                               |
|   3 | 新部署コード | 文字 | 256  |  ○   | 変更後の部署コード                 | 組織情報.EMILY所属コード                        |
|   4 | 親部署コード | 文字 | 256  |  ○   | この部署の親となる部署の部署コード | 組織情報.親組織に紐づく組織情報.EMILY所属コード |




## トヨクモユーザー情報ファイル
トヨクモに登録／削除するユーザーの情報を登録するファイル。

### ファイルフォーマット
| 項目           | 内容                                                                                                         |
| :------------- | :----------------------------------------------------------------------------------------------------------- |
| 種類           | csv                                                                                                          |
| ファイル名     | トヨクモユーザー情報.csv                                                                                     |
| 文字コード     | UTF-8                                                                                                        |
| 改行コード     | CRLF                                                                                                         |
| タイトル行     | あり                                                                                                         |
| エスケープ     | なし                                                                                                         |
| 全量／差分     | 全量                                                                                                         |
| 連携タイミング | 就業者所属情報.基準日（発令日）                                                                              |
| 抽出条件       | 次の①、②両方に該当する就業者                                                                                 |
|                | ①就業者情報.就業者区分が(役員、社員、契約社員、出向社員、直接雇用スタッフ、直接雇用シニアスタッフ)のいずれか |
|                | ②基準日時点で在籍中 または 退職(就業者情報.退職／契約終了日＝基準日)                                         |
| その他         | 登録済でファイルにないデータは削除されない為、退職者の情報を出力する。                                       |

### 出力項目
|  No | 項目名         | 種別 | 桁数 | 必須 | 項目説明                             | 設定先マスターデータ                                                                             |
| --: | :------------- | :--: | :--: | :--: | :----------------------------------- | :----------------------------------------------------------------------------------------------- |
|   1 | 現ログイン名   | 数字 | 256  |  ○   | マンナンバー下６桁                   | 就業者情報.マンナンバー                                                                          |
|   2 | 名前           | 文字 | 256  |  ○   | 全角　姓名の間に半角スペース         | 就業者情報.姓 + " " + 就業者情報.名                                                              |
|   3 | 新ログイン名   | 数字 | 256  |  ○   | マンナンバー下６桁                   | 就業者情報.マンナンバー                                                                          |
|   4 | パスワード     | 文字 |  64  |  ○   | 初期値：ntnt＋マンナンバー下６桁     | 就業者情報.入社日／契約開始日＝発令日の場合、"ntnt"+就業者情報.マンナンバー。それ以外の場合、"*" |
|   5 | 削除フラグ     | 文字 |  1   |  ○   | 空白or１                             | 就業者が退職者の場合、"1"。それ以外の場合、""                                                    |
|   6 | よみ           | 文字 | 256  |  ○   | 全角カタカナ　姓名の間に半角スペース | 就業者情報.姓カナ + " " + 就業者情報.名カナ                                                      |
|   7 | メールアドレス | 文字 |  -   |  ○   |                                      | 就業者情報.メールアドレス                                                                        |
|   8 | 電話番号       | 数値 |  -   |      |                                      | 設定しない                                                                                       |
|   9 | 並び順         | 数値 |  -   |      |                                      | 設定しない                                                                                       |
|  10 | メモ           | 文字 |  -   |      |                                      | 設定しない                                                                                       |


## トヨクモユーザー所属部署ファイル
### ファイルフォーマット
| 項目           | 内容                                                                                                        |
| :------------- | :---------------------------------------------------------------------------------------------------------- |
| 種類           | csv                                                                                                         |
| ファイル名     | ユーザー所属部署.csv                                                                                        |
| 文字コード     | UTF-8                                                                                                       |
| 改行コード     | CRLF                                                                                                        |
| タイトル行     | あり                                                                                                        |
| エスケープ     | なし                                                                                                        |
| 全量／差分     | 全量                                                                                                        |
| 連携タイミング | 就業者所属情報.基準日（発令日）(トヨクモユーザー情報ファイル連携後)                                         |
| 抽出条件       | 就業者情報.就業者区分が(役員、社員、契約社員、出向社員、直接雇用スタッフ、直接雇用シニアスタッフのいずれか) |
| その他         | 登録済でファイルにないデータは削除されない。<br>部署コードにはEMILY所属コードを使用する。                   |


### 出力項目
|  No | 項目名       | 種別 | 桁数 | 必須 | 項目説明               | 設定先マスターデータ                           |
| --: | :----------- | :--: | :--: | :--: | :--------------------- | :--------------------------------------------- |
|   1 | ログイン名   | 文字 | 256  |  ○   | ユーザーのキーとなるID | 就業者情報.マンナンバー                        |
|   2 | 部署コード1  | 文字 | 256  |  ○   | 主務の部署コード       | 就業者所属情報(主務)の組織情報.EMILY所属コード |
|   3 | 部署コード2※ | 文字 | 256  |  ○   | 兼務の部署コード       | 就業者所属情報(兼務)の組織情報.EMILY所属コード |

※行ごとに、兼務する部署がある場合は列を増やす。タイトル行や他行の列を増やす必要はない。
