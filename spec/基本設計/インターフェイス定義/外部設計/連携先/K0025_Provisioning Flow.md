## 承認者情報ファイル
Provisioning Flowにおいて承認者権限を持つ就業者の一覧。

### ファイルフォーマット
| 項目           | 内容                                                                                                 |
| :------------- | :--------------------------------------------------------------------------------------------------- |
| 種類           | csv                                                                                                  |
| ファイル名     | 承認者情報.csv                                                                                       |
| 文字コード     | UTF-8                                                                                                |
| 改行コード     | CRLF                                                                                                 |
| タイトル行     | あり                                                                                                 |
| エスケープ     | なし                                                                                                 |
| 全量／差分     | 全量                                                                                                 |
| 連携タイミング | 就業者所属情報(主務／兼務).基準日(発令日) 、連携先システム情報(Provisioning Flow).基準日(申請承認日) |
| 抽出条件       | 下記①②のどちらかに該当する就業者                                                                     |
|                | ①就業者所属情報(主務／兼務)の役職情報.ポスト長がtrue                                                 |
|                | ②就業者情報.ProvisioningFlow承認者権限がtrue                                                         |

### 出力項目
|  No | 項目名             | 種別 | 桁数 | 必須 | 項目説明 | 設定元マスターデータ                          |
| --: | :----------------- | :--: | :--: | :--: | :------- | :-------------------------------------------- |
|   1 | 部署名             | 文字 |      |  ○   |          | 就業者所属情報(主務／兼務)の組織情報.組織名称 |
|   2 | 承認者マンナンバー | 文字 |      |  ○   |          | 就業者情報.マンナンバー                       |


## ユーザーマスターファイル
Provisioning Flowにおいて利用者権限を持つ就業者の一覧。

### ファイルフォーマット
| 項目           | 内容                                                          |
| :------------- | :------------------------------------------------------------ |
| 種類           | csv                                                           |
| ファイル名     | ユーザーマスター.csv                                          |
| 文字コード     | UTF-8                                                         |
| 改行コード     | CRLF                                                          |
| タイトル行     | あり                                                          |
| エスケープ     | なし                                                          |
| 全量／差分     | 全量                                                          |
| 連携タイミング | 就業者所属情報(主務／兼務).基準日(発令日)                     |
| 抽出条件       | 就業者情報.雇用形態が(役員、社員、契約社員、出向者)のいずれか |

### 出力項目
|  No | 項目名             | 種別 | 桁数 | 必須 | 項目説明 | 設定元マスターデータ                                                                    |
| --: | :----------------- | :--: | :--: | :--: | :------- | :-------------------------------------------------------------------------------------- |
|   1 | 所属               | 文字 |      |  ○   |          | 就業者所属情報(主務)の組織情報.組織名称                                                 |
|   2 | ユーザー           | 文字 |      |  ○   |          | 就業者情報.姓 + " " + 就業者情報.名                                                     |
|   3 | UserPrincipalName  | 文字 |      |  ○   |          | 就業者情報.マンナンバー + "@nhk-tech.co.jp"                                             |
|   4 | ユーザー（検索用） | 文字 |      |  ○   |          | 就業者情報.姓 + " " + 就業者情報.名 + " " + 就業者情報.マンナンバー + "@nhk-tech.co.jp" |
