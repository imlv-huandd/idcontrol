## 機能概要
連携システムと連携インターフェイスの一覧を表示する。
システムの追加・変更・削除、インターフェイスの追加・変更・削除を選択する。

【表示仕様】
- システム行：[折畳] システム名 | 連携種別 | [インターフェイスの追加] [変更] [削除]
- インターフェイス行：インターフェイス名 | [変更] [削除]（左側にインデント）
- 折り畳みボタン：「－」展開状態、「＋」折り畳み状態
- 初期表示時：システム行のみ表示（折り畳みボタンは「－」）
- 表示順序：連携元システム → 連携先システム → 登録順

## イベント詳細
### 初期表示
- ログイン中のテナントに紐づく連携システム一覧を取得し、テーブルに表示する
  - system_master、system_interfaceから該当テナントのシステム一覧とインターフェイス一覧を取得
- 初期表示時は、インターフェイス行は非表示とし、システム行のみ表示する
- 折り畳みボタンは「－」（展開状態）で初期化

### システム追加ボタン押下
- システム追加画面に遷移する
- テナントIDを引き渡す

### 折り畳みボタン押下
- 押下されたシステム行に紐づくインターフェイス行の表示/非表示を切り替える
- 折り畳みボタンの表示を切り替える
  - 展開時：「－」→「＋」
  - 閉じる時：「＋」→「－」

### インターフェイス追加ボタン押下
- インターフェイス追加画面に遷移する
- テナントID、システムIDを引き渡す

### システム変更ボタン押下
- システム変更画面に遷移する
- テナントID、システムIDを引き渡す

### システム削除ボタン押下
- **削除確認チェック**を行う
  - キャンセルの場合、処理を終了する
- **システム削除可否チェック**を行う
  - バリデーションエラーの場合、エラーメッセージを表示し終了する
- 該当システムを削除する
  - system_masterから該当レコードを削除
- 画面を再表示する

### インターフェイス変更ボタン押下
- インターフェイス変更画面に遷移する
- テナントID、システムID、インターフェイスIDを引き渡す

### インターフェイス削除ボタン押下
- **削除確認チェック**を行う
  - キャンセルの場合、処理を終了する。
- サーバーにシステム削除要求を送信する。
- **テナント管理者チェック**を行う。
  - バリデーションエラーの場合、エラーメッセージを表示し終了する
- **インターフェイス削除可否チェック**を行う
  - バリデーションエラーの場合、エラーメッセージを表示し終了する
- 該当インターフェイスを削除する
  - system_interfaceから該当レコードを削除
- 画面を再表示する


## バリデーション定義
| No. | バリデーション名                 | バリデーション内容                                               | メッセージID |
| --: | :------------------------------- | :--------------------------------------------------------------- | :----------- |
|   1 | 削除確認チェック                 | 削除確認ダイアログを表示し、ユーザーの確認を取得する             |              |
|   2 | テナント管理者チェック           | ユーザーが対象テナントのテナント管理者権限を持っていること       |              |
|   2 | システム削除可否チェック         | 該当システムに紐づくインターフェイスが存在しないこと             |              |
|   3 | インターフェイス削除可否チェック | 該当インターフェイスに紐づく実行履歴、実行キューが存在しないこと |              |
