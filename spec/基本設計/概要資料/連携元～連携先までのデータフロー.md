# 連携元～連携先までのフロー


## OBIC、電子承認からの就業者情報の連携
### 1.連携元システムへ新しいデータがあるかチェック
  * 対象システム・インターフェイスは`システムマスター`／`連携元インターフェイス`から取得する。
### 2.存在する場合は一時テーブルへのデータの取込
  * 取込先は`連携元システム取込データ`とする。
  * 取込レコードはインターフェイス定義（`連携元インターフェイス項目` or `連携元インターフェイスJSON`）に沿って取込みとバリデーションを行う。
### 3.取り込んだデータを元に、新しい基準日での就業者情報、就業者所属情報を登録
  * `マスターデータマッピング`に従い`就業者情報`／`就業者所属情報`を登録・更新する。
    * 取込前後のデータで差分がある場合のみ登録、更新を行う。（基準日及び取込対象外の項目を除く）
### 4.連携先システムごとに更新処理を実行
  * 変更前後の`就業者情報`／`就業者所属情報`を取得する。
  * `就業者情報`／`就業者所属情報`を元に`連携先システムデータ`にルールベースのデータを登録／更新する。
    * データ抽出条件は`連携先インターフェイス`.`詳細設定.pickupCondition`を参照する。
    * `連携先システムデータ`の出力データに設定する項目は`連携先システムデータ項目`で決定し、`連携先システムデータマッピング`に従って値を算出／設定する。
    * 更新前後のデータで差分がある場合のみ登録、更新を行う。（基準日及びシーケンス番号を除く）
    * 自動削除する際の猶予期間は`連携先インターフェイス`の削除猶予関連設定を参照する。
### 5.連携先システムにデータ連携
  * 出力対象となる`連携先システムデータ`を抽出する。
    * `連携先インターフェイス`.`詳細設定`で優先度情報が設定されている場合、優先度に基づいたデータを抽出する。
    * 出力除外は`就業者情報スキップ設定`を参照する。
    * 上書き指定は`就業者情報上書設定`を優先する。
  * `連携先インターフェイスフォーマット`に従い、出力データを生成する。
  * 生成結果を各連携先へ連携する（ファイル出力／API等は`連携先インターフェイス`.`インターフェイス種別`に従う）。
