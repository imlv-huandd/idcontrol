## 登録ファイル
タクシーアプリS.RIDEが利用できるエリアの部署に所属（異動も含む）する役員／社員の情報を連携するファイル。

### ファイルフォーマット
| 項目           | 内容                                                                                                                                                                    |
| :------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 種類           | CSV                                                                                                                                                                     |
| ファイル名     | 登録.csv                                                                                                                                                                |
| 文字コード     | UTF-8                                                                                                                                                                   |
| 改行コード     | CRLF                                                                                                                                                                    |
| タイトル行     | あり                                                                                                                                                                    |
| エスケープ     | なし                                                                                                                                                                    |
| 全量／差分     | 差分                                                                                                                                                                    |
| 連携タイミング | 就業者所属情報.基準日（発令日）                                                                                                                                         |
| 抽出条件       | 次の①に該当し、②③④のどちらかに該当する就業者                                                                                                                            |
|                | ①就業者情報.就業者区分が(役員、社員)のいずれか                                                                                                                          |
|                | ②新規登録（就業者情報.入社日／契約開始日＝基準日）かつ 就業者所属情報(主務)の組織情報.タクシーアプリS.RIDE使用可否が"可能"                                              |
|                | ③就業者所属情報(主務)の組織情報.タクシーアプリS.RIDE使用可否が"可能"に変更となった（1世代前の情報と比較。**所属異動の有無に拠らず使用可否の変更有無のみで判定を行う**） |
|                | ④就業者所属情報(主務)の組織情報.タクシーアプリGO使用可否が"可能" かつ 就業者情報.姓、名、メールアドレスのいずれかが変更となった                                         |

### 出力項目
|  No | 項目名         | 種別 | 桁数 | 必須 | 項目説明          | 設定元マスターデータ                                        |
| --: | :------------- | :--: | :--: | :--: | :---------------- | :---------------------------------------------------------- |
|   1 | 項番           | 数字 |  -   |      | 未使用            | 1始まりの行番号                                             |
|   2 | 名前           | 文字 |  20  |  ○   |                   | 就業者情報.姓 + "　" + 就業者情報.名                        |
|   3 | 名前（ﾌﾘｶﾞﾅ）  | 文字 |  20  |  ○   |                   | 就業者情報.姓カナ + " " + 就業者情報.名カナ（半角カナ変換） |
|   4 | 暗証番号       | 数字 |  10  |  ○   | マンナンバー下4桁 | 就業者情報.マンナンバーの下4桁                              |
|   5 | メールアドレス | 文字 |  30  |  ○   |                   | 就業者情報.メールアドレス                                   |


## 削除ファイル
退職や、タクシーアプリGOが利用できないエリアの部署に異動した役員／社員の情報を連携するファイル。

### ファイルフォーマット
| 項目           | 内容                                                                                                                                                                    |
| :------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 種類           | CSV                                                                                                                                                                     |
| ファイル名     | 削除.csv                                                                                                                                                                |
| 文字コード     | UTF-8                                                                                                                                                                   |
| 改行コード     | CRLF                                                                                                                                                                    |
| タイトル行     | あり                                                                                                                                                                    |
| エスケープ     | なし                                                                                                                                                                    |
| 全量／差分     | 差分                                                                                                                                                                    |
| 連携タイミング | 就業者所属情報.基準日（発令日）                                                                                                                                         |
| 抽出条件       | 次の①に該当し、②③のどちらかに該当する就業者                                                                                                                             |
|                | ①就業者情報.就業者区分が(役員、社員)のいずれか                                                                                                                          |
|                | ②退職（就業者情報.退職日／契約終了日＝基準日）                                                                                                                          |
|                | ③就業者所属情報(主務)の組織情報.タクシーアプリS.RIDE使用可否が"不可"に変更となった（1世代前の情報と比較。**所属異動の有無に拠らず使用可否の変更有無のみで判定を行う**） |

### 出力項目
|  No | 項目名       | 種別 | 桁数 | 必須 | 項目説明           | 設定元マスターデータ                 |
| --: | :----------- | :--: | :--: | :--: | :----------------- | :----------------------------------- |
|   1 | 項番         | 数字 |  -   |      | 未使用             | 1始まりの行番号                      |
|   2 | カードご名義 | 文字 |  20  |  ○   | 姓+全角スペース+名 | 就業者情報.姓 + "　" + 就業者情報.名 |
