## 機能概要
検索結果やデータ一覧を複数ページに分割して表示する際の共通コンポーネント。


## 項目定義

### ページネーションエリア

| No. | 項目名           | 表示文言                      | I/O | オブジェクト | DBマッピング | 初期値 | 備考                       |
| --: | :--------------- | :---------------------------- | :-: | :----------- | :----------: | :----- | :------------------------- |
|   1 | 現在表示         | XXX件（Y件目～Z件目を表示中） |  O  | ラベル       |              |        | 全体件数と表示中件数を表示 |
|   2 | 先頭ページボタン | «                             |  -  | ボタン       |              |        | 先頭ページに移動           |
|   3 | 前ページボタン   | ‹                             |  -  | ボタン       |              |        | 前のページに移動           |
|   4 | ページ番号ボタン | 1, 2, 3...                    |  I  | ボタン       |              |        | 最大5ページ分表示          |
|   5 | 次ページボタン   | ›                             |  -  | ボタン       |              |        | 次のページに移動           |
|   6 | 最終ページボタン | »                             |  -  | ボタン       |              |        | 最終ページに移動           |


## 機能仕様

### イベント定義
| No. | イベント名           | トリガー条件             | イベント概要                     |
| --: | :------------------- | :----------------------- | :------------------------------- |
|   1 | 初期表示             | -                        | ページネーションの初期表示を行う |
|   2 | 先頭ページボタン押下 | 先頭ページボタンクリック | 先頭ページを表示する             |
|   3 | 前ページボタン押下   | 前ページボタンクリック   | 前のページを表示する             |
|   4 | ページ番号ボタン押下 | ページ番号ボタンクリック | 指定したページを表示する         |
|   5 | 次ページボタン押下   | 次ページボタンクリック   | 次のページを表示する             |
|   6 | 最終ページボタン押下 | 最終ページボタンクリック | 最終ページを表示する             |


## イベント詳細

### 初期表示

- データ件数が1ページ分（20件）以下の場合、ページングエリアを非表示とする。
- データ件数が1ページ分を超える場合、ページングエリアを表示する。
  - 総ページ数を計算する。
  - 現在ページ番号と表示範囲を表示する（例：「100件（1件目～20件目を表示中）」）。
  - ページ番号ボタンを最大5ページ分表示する（現在ページを中心に表示）。
  - 1ページ目の場合、先頭ページ・前ページボタンを無効化する。
  - 最終ページの場合、次ページ・最終ページボタンを無効化する。

### 先頭ページボタン押下

- 現在ページを1ページ目に設定する。
- 1ページ目のデータを取得し、一覧を更新する。
- ページング情報を更新する。
  - 先頭ページ・前ページボタンを無効化する。
  - 次ページ・最終ページボタンを有効化する。
  - ページ番号ボタンを再生成する。
  - 現在の表示範囲を更新する。

### 前ページボタン押下

- 現在ページを1つ前に設定する。
- 前ページのデータを取得し、一覧を更新する。
- ページング情報を更新する。
  - 1ページ目の場合、先頭ページ・前ページボタンを無効化する。
  - 次ページ・最終ページボタンを有効化する。
  - ページ番号ボタンを再生成する。
  - 現在の表示範囲を更新する。

### ページ番号ボタン押下

- クリックされたページ番号に設定する。
- 指定されたページのデータを取得し、一覧を更新する。
- ページング情報を更新する。
  - ページ番号ボタンを再生成する。
  - 1ページ目の場合、先頭ページ・前ページボタンを無効化する。それ以外は有効化する。
  - 最終ページの場合、次ページ・最終ページボタンを無効化する。それ以外は有効化する。
  - 現在の表示範囲を更新する。

### 次ページボタン押下

- 現在ページを1つ後に設定する。
- 次ページのデータを取得し、一覧を更新する。
- ページング情報を更新する。
  - 先頭ページ・前ページボタンを有効化する。
  - 最終ページの場合、次ページ・最終ページボタンを無効化する。
  - ページ番号ボタンを再生成する。
  - 現在の表示範囲を更新する。

### 最終ページボタン押下

- 現在ページを最終ページに設定する。
- 最終ページのデータを取得し、一覧を更新する。
- ページング情報を更新する。
  - 先頭ページ・前ページボタンを有効化する。
  - 次ページ・最終ページボタンを無効化する。
  - ページ番号ボタンを再生成する。
  - 現在の表示範囲を更新する。


## 仕様

### ページサイズ
- デフォルト：20件/ページ
- 各画面で設定変更可能

### ページ番号ボタン表示ルール
- 最大5ページ分のボタンを表示する。
- 現在ページを中心に表示する。
- 総ページ数が5ページ以下の場合は、すべてのページ番号を表示する。
- 総ページ数が6ページ以上の場合：
  - 現在ページが1～3ページ目：1～5を表示
  - 現在ページが最終から3ページ目以降：最終-4～最終を表示
  - それ以外：現在ページ-2～現在ページ+2を表示

### 表示範囲の計算
- 開始位置：(現在ページ - 1) × ページサイズ + 1
- 終了位置：min(現在ページ × ページサイズ, 総件数)
- 表示形式：「{総件数}件（{開始位置}件目～{終了位置}件目を表示中）」
