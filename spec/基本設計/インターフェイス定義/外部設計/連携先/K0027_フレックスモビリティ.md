## フレックスモビリティ利用申請ファイル
### ファイルフォーマット
| 項目           | 内容                                                                                                                                                                                                   |
| :------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 種類           | CSV                                                                                                                                                                                                    |
| ファイル名     | フレックスモビリティ利用申請.csv                                                                                                                                                                       |
| 文字コード     | UTF-8                                                                                                                                                                                                  |
| 改行コード     | CRLF                                                                                                                                                                                                   |
| タイトル行     | あり                                                                                                                                                                                                   |
| エスケープ     | なし                                                                                                                                                                                                   |
| 全量／差分     | 差分                                                                                                                                                                                                   |
| 連携タイミング | 連携先システム情報.基準日(利用開始／終了希望日、発令日) ※セキュリティグループ設定ファイル連携後                                                                                                        |
| 抽出条件       | 下記①②③のいずれかに該当する連携先システム情報(フレックスモビリティ)                                                                                                                                    |
|                | ①フレックスモビリティの利用申請に紐づく連携先システム情報(社給PC)が存在する。                                                                                                                          |
|                | ②フレックスモビリティの解除申請に紐づく連携先システム情報(フレックスモビリティ)が存在する。                                                                                                            |
|                | ③連携先システム情報(フレックスモビリティ)が存在 かつ 利用解除(就業者情報.NTAD利用がfalse かつ 就業者情報(1世代前).NTAD利用がtrueまたは退職（就業者情報.基準日＝就業者情報.退職日／契約終了日／離任日)) |
