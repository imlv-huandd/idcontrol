## NTAD就業者情報ファイル
NTADへの就業者情報の登録、情報変更、登録削除の情報を出力するファイル。

### ファイルフォーマット
| 項目           | 内容                                                                                                                                               |
| :------------- | :------------------------------------------------------------------------------------------------------------------------------------------------- |
| 種類           | csv                                                                                                                                                |
| ファイル名     | NTAD就業者情報ファイル.csv                                                                                                                         |
| 文字コード     | UTF-8                                                                                                                                              |
| 改行コード     | CRLF                                                                                                                                               |
| タイトル行     | あり                                                                                                                                               |
| エスケープ     | あり                                                                                                                                               |
| 全量／差分     | 差分                                                                                                                                               |
| 連携タイミング | 就業者情報.基準日                                                                                                                                  |
| 抽出条件       | 下記①②③いずれかに該当する就業者                                                                                                                    |
|                | ①登録(就業者情報.NTAD利用がtrue かつ 就業者情報(1世代前).NTAD利用がfalseまたは存在しない)                                                          |
|                | ②削除((就業者情報.NTAD利用がfalse かつ 就業者情報(1世代前).NTAD利用がtrue) または 退職（就業者情報.基準日＝就業者情報.退職日／契約終了日／離任日)) |
|                | ③変更(下記③-1、③-2のどちらかに該当する)                                                                                                            |
|                | ・③-1 所属異動(就業者所属情報(主務)の組織コード、役職コードのいずれかが1世代前と差分がある)                                                        |
|                | ・③-2 姓、名、姓かな、名かな、メールのいずれかが1世代前と差分がある                                                                                |

### 出力項目
|  No | 項目名           | 種別 | 必須 | 項目説明                                                    | 設定元マスターデータ                                                                                              |
| --: | :--------------- | :--: | :--: | :---------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------- |
|   1 | 登録／変更／削除 | 文字 |  〇  |                                                             | 登録の場合、"登録"。削除の場合、"削除"。それ以外の場合、"変更"                                                    |
|   2 | 社員番号         | 文字 |  〇  |                                                             | 就業者情報.マンナンバー                                                                                           |
|   3 | 姓               | 文字 |  〇  |                                                             | 就業者情報.姓                                                                                                     |
|   4 | 名               | 文字 |  〇  |                                                             | 就業者情報.名                                                                                                     |
|   5 | 姓かな           | 文字 |  〇  |                                                             | 就業者情報.姓カナ（ひらがな変換）                                                                                 |
|   6 | 名かな           | 文字 |  〇  |                                                             | 就業者情報.名カナ（ひらがな変換）                                                                                 |
|   7 | 部署             | 文字 |  〇  |                                                             | 就業者所属情報(主務)の組織情報.組織名称                                                                           |
|   8 | 役職             | 文字 |  〇  |                                                             | 就業者所属情報(主務)の役職情報.役職名称                                                                           |
|   9 | 表示順           | 文字 |  〇  | Outlookの宛先での表示順。**大きい値の方が先に表示される。** | (999 - 就業者所属情報(主務)の役職情報.序列)の文字列 + (999999 - 就業者情報.マンナンバー)の文字列 （例:123123456） |
|  10 | メール           | 文字 |  〇  |                                                             | 就業者情報.メールアドレス                                                                                         |

## セキュリティグループクリアファイル
セキュリティグループが変更となる就業者について、新しいセキュリティグループを設定する前に全てのセキュリティグループを削除する。

### ファイルフォーマット
| 項目           | 内容                                                                                                                          |
| :------------- | :---------------------------------------------------------------------------------------------------------------------------- |
| 種類           | csv                                                                                                                           |
| ファイル名     | セキュリティグループクリアファイル.csv                                                                                        |
| 文字コード     | UTF-8                                                                                                                         |
| 改行コード     | CRLF                                                                                                                          |
| タイトル行     | あり                                                                                                                          |
| エスケープ     | あり                                                                                                                          |
| 全量／差分     | 差分                                                                                                                          |
| 連携タイミング | 連携先システム情報.基準日(発令日、申請承認日) ※NTAD就業者情報ファイル連携後                                                   |
| 抽出条件       | 下記①に該当し、②③のどちらかに該当する**就業者**                                                                               |
|                | ①就業者情報.NTAD利用がtrue                                                                                                    |
|                | ②所属異動(就業者所属情報(主務／兼務)の組織コード、役職コードに1世代前と差分のあるものが1つ以上存在する(兼務追加／削除も含む)) |
|                | ③利用システム追加／変更／削除(Microsoft365を含むNTAD関連の連携先システム情報で基準日のデータが1件以上存在する)                |

| 全量／差分     | 差分                                                                                                                          |
| 連携タイミング | 連携先システム情報.基準日(発令日、申請承認日) ※セキュリティグループクリアファイル連携後                                       |
| 抽出条件       | 下記①に該当し、②③のどちらかに該当する**就業者**に紐づく、基準日時点で有効なNTAD関連(**後述**)の連携先システム情報             |

### NTAD関連の連携先システム情報

|  No | 名称                        | 設定内容                                                                     |

|   4 | BOX部門別(承認)             | 就業者が承認によってアクセスできる部門別のセキュリティグループ名             |
|   5 | Microsoft Copilot利用       | 就業者がCopilotを利用する場合に設定されるセキュリティグループ名              |
|   6 | NTポータル閲覧権限          | 就業者のNTポータル閲覧権限により設定されるセキュリティグループ名             |
|   7 | Microsoft Teams Planner利用 | 就業者がTeams Plannerを利用する場合に設定されるセキュリティグループ名        |
|   8 | Microsoft Flow利用          | 就業者がFlowを利用する場合に設定されるセキュリティグループ名                 |
|   9 | タクシーアプリGO利用        | 就業者がタクシーアプリGOを利用する場合に設定されるセキュリティグループ名     |
|  10 | タクシーアプリS.RIDE利用    | 就業者がタクシーアプリS.RIDEを利用する場合に設定されるセキュリティグループ名 |
|  11 | フレックスモビリティ利用    | 就業者がフレックスモビリティを利用する場合に設定されるセキュリティグループ名 |
