## ビジネスID登録
タクシーアプリGOが利用できるエリアの部署に所属（異動も含む）する役員／社員の情報を連携するファイル。

### ファイルフォーマット
| 項目           | 内容                                                                                                                                                                |
| :------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 種類           | CSV                                                                                                                                                                 |
| ファイル名     | ビジネスID登録.csv                                                                                                                                                  |
| 文字コード     | UTF-8                                                                                                                                                               |
| 改行コード     | CRLF                                                                                                                                                                |
| タイトル行     | あり                                                                                                                                                                |
| エスケープ     | なし                                                                                                                                                                |
| 全量／差分     | 差分                                                                                                                                                                |
| 連携タイミング | 就業者所属情報.基準日（発令日）                                                                                                                                     |
| 抽出条件       | 次の①に該当し、②③のどちらかに該当する就業者                                                                                                                         |
|                | ①就業者情報.就業者区分が(役員、社員)のいずれか                                                                                                                      |
|                | ②新規登録（就業者情報.入社日／契約開始日＝基準日）かつ 就業者所属情報(主務)の組織情報.タクシーアプリGO使用可否が"可能"                                              |
|                | ③就業者所属情報(主務)の組織情報.タクシーアプリGO使用可否が"可能"に変更となった（1世代前の情報と比較。**所属異動の有無に拠らず使用可否の変更有無のみで判定を行う**） |


### 出力項目
|  No | 項目名         | 種別 | 桁数 | 必須 | 項目説明                                                                     | 設定元マスターデータ                    |
| --: | :------------- | :--: | :--: | :--: | :--------------------------------------------------------------------------- | :-------------------------------------- |
|   1 | 氏名           | 文字 |  50  |  ○   | 姓+全角スペース+名                                                           | 就業者情報.姓 + "　" + 就業者情報.名    |
|   2 | メールアドレス | 文字 |  50  |  ○   |                                                                              | 就業者情報.メールアドレス               |
|   3 | 所属           | 文字 |  50  |  ○   |                                                                              | 就業者所属情報(主務)の組織情報.組織名称 |
|   4 | 社員番号       | 数字 |  50  |  ○   |                                                                              | 就業者情報.マンナンバー                 |
|   5 | 月額上限金額   | 数字 |  15  |      | -1:上限なし、金額:上限額、空欄:法人の上限額設定を適用、0:GO BUSINESS利用不可 | 設定しない                              |


## ビジネスID情報変更／削除
退職や、タクシーアプリGOが利用できないエリアの部署に異動した役員／社員の情報を連携するファイル。

### ファイルフォーマット
| 項目           | 内容                                                                                                                                                                |
| :------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 種類           | CSV                                                                                                                                                                 |
| ファイル名     | ビジネスID削除.csv                                                                                                                                                  |
| 文字コード     | UTF-8                                                                                                                                                               |
| 改行コード     | CRLF                                                                                                                                                                |
| タイトル行     | あり                                                                                                                                                                |
| エスケープ     | なし                                                                                                                                                                |
| 全量／差分     | 差分                                                                                                                                                                |
| 連携タイミング | 就業者所属情報.基準日（発令日）                                                                                                                                     |
| 抽出条件       | 次の①に該当し、②③④⑤のいずれかに該当する就業者                                                                                                                       |
|                | ①就業者情報.就業者区分が(役員、社員)のいずれか                                                                                                                      |
|                | ②退職（就業者情報.退職日／契約終了日＝基準日）                                                                                                                      |
|                | ③就業者所属情報(主務)の組織情報.タクシーアプリGO使用可否が"不可"に変更となった（1世代前の情報と比較。**所属異動の有無に拠らず使用可否の変更有無のみで判定を行う**） |
|                | ④使用可能部署間の所属異動（上記③の比較が"可能"⇒"可能"で変更前後の部門コード(基軸コード)が異なる）                                                                       |
|                | ⑤就業者所属情報(主務)の組織情報.タクシーアプリGO使用可否が"可能" かつ 就業者情報.姓、名、メールアドレスのいずれかが変更となった                                     |

### 出力項目
|  No | 項目名          | 種別 | 桁数 | 必須 | 項目説明                                                                     | 設定元マスターデータ                                                                                                            |
| --: | :-------------- | :--: | :--: | :--: | :--------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------ |
|   1 | 氏名            | 文字 |  50  |  ○   | 姓+全角スペース+名                                                           | 就業者情報.姓 + "　" + 就業者情報.名                                                                                            |
|   2 | メールアドレス  | 文字 |  50  |  ○   |                                                                              | 就業者情報.メールアドレス                                                                                                       |
|   3 | 所属            | 文字 |  50  |  ○   |                                                                              | 就業者所属情報(主務)の組織情報.組織名称                                                                                         |
|   4 | 社員番号        | 数字 |  50  |  ○   |                                                                              | 就業者情報.マンナンバー                                                                                                         |
|   5 | ID              | 文字 |  15  |      | タクシーGOシステムからの自動割り当て                                         | 設定しない                                                                                                                      |
|   6 | ステータス      | 文字 |  3   |      | 未連携or連携中                                                               | 設定しない                                                                                                                      |
|   7 | 月額上限金額    | 数字 |  15  |      | -1:上限なし、金額:上限額、空欄:法人の上限額設定を適用、0:GO BUSINESS利用不可 | 設定しない                                                                                                                      |
|   8 | 削除（1を入力） | 数字 |  1   |  ○   | 就業者を削除する場合、"1"を指定する                                          | 就業者が退職の場合、"1"。就業者所属情報(主務)の組織情報.タクシーアプリGO使用可否が"不可"の場合、"1"。それ以外の場合、設定しない |
