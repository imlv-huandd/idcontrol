## 承認者情報ファイル
### ファイルフォーマット
| 項目           | 内容                                      |
| -------------- | ----------------------------------------- |
| 種類           | CSV                                       |
| ファイル名     | 承認権情報.csv                            |
| 文字コード     | UTF-8                                     |
| 改行コード     | CRLF                                      |
| タイトル行     | あり                                      |
| エスケープ     | なし                                      |
| 全量／差分     | 全量                                      |
| 抽出条件       | 就業者所属情報.役職コード IN (部長、室長) |
| 連携タイミング | 発令日                                    |

### 出力項目
| No  | 項目名   | 種別 | 桁数 | 必須 | 項目説明 | 設定元マスターデータ                |
| --- | -------- | ---- | ---- | ---- | -------- | ----------------------------------- |
| 1   | 所属     | 文字 |      |      |          | 就業者所属情報.グループ名称         |
| 2   | IT管理者 | 文字 |      |      |          | 就業者情報.姓 + " " + 就業者情報.名 |


### 処理フロー

```mermaid
sequenceDiagram
    participant 就業者所属情報更新
    participant ID管理システム
    participant RPA
    participant Provisioning Flow
    
    就業者所属情報更新->>ID管理システム: 就業者所属情報更新
    ID管理システム->>RPA: 起動依頼 (REST API)
    RPA->>ID管理システム: ファイルダウンロード (REST API)
    RPA->>Provisioning Flow: ファイル投入
```
